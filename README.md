 A dynamic web-based fitness management platform with gym info, shopping features, and interactive schedules. Built using HTML, CSS, JavaScript, Node.js, and MySQL.

 
# Core Fitness Web Application

Core Fitness is a dynamic and responsive web-based fitness management platform designed to streamline gym operations and enhance user experience. The platform not only provides essential gym-related information but also integrates an e-commerce module for purchasing fitness-related products such as supplements, equipment, and accessories.

## 🔧 Features

- 🏋️‍♂️ Home, About, Trainers, Features, and Subscription sections
- 🛒 Fully functional shopping page with:
  - Product filtering, categorization, and search
  - Add to cart, purchase flow (using local storage)
  - Planned MySQL integration for product and order data
- 📅 Weekly training schedule with CRUD operations
- 👤 User profile management
- 🌐 Clean, modern UI with responsive design using HTML, CSS, and JavaScript
- ⚙️ Backend integration with Node.js and Express.js

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MySQL (planned)
